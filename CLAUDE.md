## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues on `jonstuebe/shelfgames`, using the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The default five triage labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one root `GLOSSARY.md` and `docs/adr/`, both created lazily by `/domain-modeling`. See `docs/agents/domain.md`.
